How it works

Three moments. No buttons.

You never open WriteFix or paste text into it. It sits in the menu bar and works on the text field you are already in.

write

You type the way you type

Fast, lowercase, no full stops. Mail, chat, notes, a browser, the terminal.

You stop for one second

That pause is the signal. The last thing you typed goes to the model on your own machine.

i dont no wat to doI don't know what to do.

The text repairs itself

Only the part that changed is retyped, starting from the back, the way a friend would fix it over your shoulder.

Two strands: what you typed, and what it writes

The model reads your messy sentence as one strand and writes a clean one beside it, letter group by letter group. The links between them are what it pays attention to.

Features

Small on purpose.

Private by design

The model runs on your Mac. Nothing you type leaves it, and it works with Wi-Fi off.

Works in any app

It fixes text in the field you are already typing in. No copy and paste, no separate window.

Faster than a blink

About 22 milliseconds for a sentence, so the fix lands before you start the next thought.

Pause any time

One shortcut turns it off, the same one turns it back on. You can also switch it off per app.

Undo a bad fix

If it gets one wrong, one shortcut puts your words back and saves the case so the next model learns from it.

Skips code and commands

It is built for ordinary sentences. Code, file paths, links and common shell commands are left untouched.

Controls

Two shortcuts run it.

Press the real keys on your keyboard and watch these light up.

control+option+P

Pause and resume

The menu bar shows ✓Aa when it is on and ⏸Aa when it is paused.

control+option+Z

Undo the last fix

Your original words come back exactly as you typed them, and that text is left alone afterwards.

Install guide

On your Mac in four steps.

This is a developer-style install for now. It takes about five minutes, most of it waiting for one download.

You need

  • A Mac with Apple Silicon (M1 or newer)
  • macOS 13 or later
  • Python 3.10 or later
  • Xcode Command Line Tools
  • About 1 GB of free space
Open on GitHub

The repository is invite-only during the prototype. Ask Rishi for access first.

  1. Get the command line tools

    Skip this if you already use git or Xcode. A system window opens; click Install.

    xcode-select --install

  2. Download WriteFix

    It has to live in a folder called writefix in your home folder, because the app loads its code from there.

    git clone https://github.com/rishiraj38/writefix.git ~/writefix

  3. Run the installer

    It sets up Python packages in their own folder, builds the menu-bar app and opens it. Look for …Aa in the menu bar.

    cd ~/writefix && ./install.sh

    That installs WF-1 Mini. For WF-1 Large, run this instead. It downloads 187 MB more, and you can switch back any time with ./scripts/use_model.sh mini.

    cd ~/writefix && ./install.sh large

  4. Allow it to see your typing

    macOS asks once. Open System Settings, then Privacy & Security, then Accessibility, and switch on WriteFixApp. The icon turns to ✓Aa. Type four or more words anywhere and stop for a second.

Prototype status

What it can do today.

This is an early build shared with friends. Here is where it stands, measured on the current model.

Works now

  • Capitals and punctuation: full stops, commas, question marks, apostrophes.
  • Common typos: tommorow, becuase, realy, freind, resturant.
  • Chat shorthand: u, pls, abt become you, please, about.
  • Word errors on test text: 27% before, 9% after with Mini, 5% with Large.
  • Harder slips, with Large: "alot", "this are" and "pls" now get fixed.

Not yet

  • Long, messy messages: on very rough text with tech words, both models still leave about a third of the words wrong.
  • Correct text: Mini changes about 5 in 100 sentences that were already fine, Large about 1.
  • English only, and Mac only.
  • Tested apps: TextEdit so far. Others are being tried now.
